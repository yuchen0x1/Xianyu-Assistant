## 新增研究与本项目采用方向

- **zhinianboke/xianyu-auto-reply（直接）**　FastAPI 管理层、消息连接、规则发货和推广子系统。分离平台接入和运营页面的路径可参考。 [项目文档和源码](https://github.com/zhinianboke/xianyu-auto-reply)
- **245867/xianyu-auto-delivery（直接）**　FastAPI + React 工作台，订单与库存集中操作，通知渠道配置独立。可参考紧凑的待处理队列和回执。 [项目文档和源码](https://github.com/245867/xianyu-auto-delivery)
- **xie-good/xianyu-agent（直接）**　Python 客服与 Vue 管理面板。显式人工接管与连接状态对本项目有参考价值。GitHub API 未返回可确认的许可证。 [项目文档和源码](https://github.com/xie-good/xianyu-agent)
- **louislam/dockge（运维参考）**　TypeScript / Vue。Compose 文件为部署入口，能从堆栈回到日志和状态。吸收单一 Compose 入口与可观测健康状态。 [项目文档和源码](https://github.com/louislam/dockge)
- **crazy-max/diun（运维参考）**　Go 镜像更新通知。发现新版本与部署分开。容器用发布检查提示，运维通过新镜像升级。 [项目文档和源码](https://github.com/crazy-max/diun)
- **louislam/uptime-kuma（运维参考）**　Node / Vue，自托管监控。探针、状态页和通知区分故障原因。借鉴健康门禁与运行日志。 [项目文档和源码](https://github.com/louislam/uptime-kuma)
- **gethomepage/homepage（运维参考）**　Next.js 管理导航支持服务状态、配置和响应式小部件。适合作为移动 Web 小屏/空状态参考。 [项目文档和源码](https://github.com/gethomepage/homepage)
- **dgtlmoon/changedetection.io（运维参考）**　Python 服务，支持容器持久数据、变化检查、历史和通知。对标发布和竞品变化监测。 [项目文档和源码](https://github.com/dgtlmoon/changedetection.io)
- **renovatebot/renovate（技术参考）**　TypeScript 依赖自动化，支持分组、排期与发布策略。保留已有 Dependabot，借鉴把 Playwright 依赖升级作为联动项。 [项目文档和源码](https://github.com/renovatebot/renovate)
- **immich-app/immich（间接）**　TypeScript 与 Flutter，多客户端共享服务，Compose 部署并维护升级文档。证明移动端要有高频独立流程才值得承担维护成本。 [项目文档和源码](https://github.com/immich-app/immich)
- **navidrome/navidrome（运维参考）**　Go 服务与 Web 前端，按部署路径发包，独立管理存储目录。参考服务器版本更新与客户端访问分开。 [项目文档和源码](https://github.com/navidrome/navidrome)
- **sqlitebrowser/sqlitebrowser（技术参考）**　Qt/C++ 跨平台 SQLite 桌面工具。可参考本地数据维护与导入预览。产品目标不同，保留服务端访问控制。 [项目文档和源码](https://github.com/sqlitebrowser/sqlitebrowser)
- **getfider/fider（间接）**　Go 服务与独立 Web 反馈界面，对标问题分类、人可读状态与贡献入口。用仓库 Issue 表单实现最小等价能力。 [项目文档和源码](https://github.com/getfider/fider)
